# Failure

Some Tabletop Sim resets preserve velocity from the previous episode. The cube can look as if it has returned to the starting pose while the full state differs. That makes repeated attempts incomparable before any controller behavior is considered.

# Decision

Pause the benchmark. Comparing success or failure across these resets would mix the intended experiment with residual simulator state. I want to bring Omar a bounded example that shows the mismatch instead of another summary score.

# What would unblock it
