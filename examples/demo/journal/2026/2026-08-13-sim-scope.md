# Scope decision

Tabletop Sim will start with one cube, one table, and a fixed gripper configuration. Omar's questions made me realize that changing objects, initial conditions, and control behavior together would make a failure harder to interpret.

# Purpose

The first task is to understand the simulation's state and repeat an attempt under the same conditions. I want a short scene description and an explicit reset procedure before collecting results that appear comparable only because the cube starts in the same place.

# Deferred work

A larger object set, policy learning, and transfer to a physical robot can wait. This exercise needs a trustworthy baseline before a failure taxonomy would say anything useful.
