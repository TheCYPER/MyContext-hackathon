# Small check

LabNotes retrieves the known records when I use their exact identifiers. That establishes a useful lookup path, but it is an easy test because the query already contains the stored name.

# Missing evidence

A person resuming a project may remember the problem without remembering the record's wording. The next test needs questions in that form, along with judgments about which notes would actually answer them. I also want cases where the collection contains no supported answer.

# Next step
