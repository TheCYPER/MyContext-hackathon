# Current state

Literature notes for a focused question about source-sequence leakage in evaluation. The August 27 scope decision replaced the broad topic robust evaluation with a smaller question that connects to Eval Notebook's split failure. The current shortlist is not a systematic review or evidence of a novel research gap.

# Note structure

A useful entry separates the author's stated claim, the evaluation setting, the supporting section or figure, and Alex's interpretation. Reading an abstract supports an abstract-level note; it does not support a detailed claim about an experiment that has not been inspected.

An eligibility note records why a paper belongs in the current question. A paper can be interesting without answering this question. Changes to the question should be dated so an earlier exclusion is not silently reinterpreted under a new scope.

# Evidence and limits

The September 10 advisor preparation assembled the narrow question and unresolved terms. It did not establish a complete paper search, independent reproduction, or a finding that prior work has overlooked leakage.

The working distinction is between different samples and independent sources. Two clips can have different filenames while sharing an underlying recording. The literature review must check how each source defines independence before comparing results.
