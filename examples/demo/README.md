# MyContext fictional demo

Every person, project, relationship, preference, event, and result in this dataset is invented. Demo Builder and Morgan are fictional characters. Atlas and Ember are fictional projects. The example dates are invented. No record describes the software's author, a real user, or a real organization.

Run `scripts/setup.sh demo` from the MyContext source repository to create a separate local Git copy under `.local/demo`. That copy has its own initial commit and no remote. Rerunning setup preserves a clean existing copy and refuses to overwrite changes.

The source examples are safe to publish because their content is synthetic. Their privacy labels demonstrate normal private-context behavior; they are not a claim that private personal data is safe to publish.

Use `scripts/setup.sh personal /absolute/new/path` to create your own blank context. Demo facts must never be copied into a real profile as if they were true.
