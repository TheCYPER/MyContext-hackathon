# Problem

Fictional demo: a reader might remember a note's answer but forget the original question. This is a proposed problem, not validated demand.

# Product direction

Explore a short trail connecting a question, selected notes, and the decision that followed.

# First validation

Compare a hand-built trail with a plain list using a few invented notes, then design a real evaluation separately.

# Current boundary

This is an unvalidated idea. It is not an implemented Atlas feature or a claim that graph navigation improves learning.
