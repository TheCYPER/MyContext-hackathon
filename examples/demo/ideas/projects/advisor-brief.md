# Problem

A meeting draft can list many activities without saying which decision needs an advisor's help. It can also repeat an obsolete result when the underlying experiment has changed.

# Product direction

Prepare a one-page draft from four fields: the current question, what was actually tried, what the evidence does and does not show, and one requested decision. Link each claim to the current project or dated event so the author can inspect it before sharing.

# First validation

Use the withdrawn clip-random result and the single-seed grouped rerun. Check that the brief asks Rhea about the valid next comparison, explicitly excludes the withdrawn result, and does not present the shortlist as a systematic literature review. Have Alex edit the brief for relevance before evaluating stylistic polish.

# Current boundary

The idea has not been implemented. It would create a draft, not schedule a meeting or send a message. The existing advisor-preparation draft is working context, not evidence that this proposed tool exists.
