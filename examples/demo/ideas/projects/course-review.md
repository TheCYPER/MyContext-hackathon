# Problem

A review sheet organised only by lecture titles can hide what Alex still cannot do. Meanwhile, a completed query exercise and an explained gradient example may be presented as if they have the same learning status.

# Product direction

Build a compact review from unresolved question records and dated attempts. Each item would show the concept, the last independent attempt, the specific missing step, and one suitable next self-check. Completed items remain available as references without displacing current gaps.

# First validation

Assemble a review using the gradient recall sequence and CourseQuery's corrected counting example. Ask Maya whether each suggested exercise targets the recorded gap, then ask Theo to check that the question tests the intended concept rather than a memorised numeric answer.

# Current boundary

No review generator or adaptive learning system has been implemented. The output would be a proposed study sheet for Alex to review, not a diagnosis of ability, a grade prediction, or a promise of improved exam performance.
