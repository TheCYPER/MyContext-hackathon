# Project Title

Which question records reveal a gap between explanation and independent solution?

# Project Description

StudyMap distinguishes reading a clear explanation from solving a fresh example without notes. Explore whether a record that explicitly separates these states makes the next study action easier to choose.

Begin with Alex's own small set of fictional course questions, not a claimed study of students. For each item, record an immediate explanation check and a delayed no-notes problem with different values or structure. Preserve the failed reasoning step. A correct repeated answer may reflect memorising the earlier example rather than transfer.

The proposed comparison is a planning tool for this scenario. It does not establish that the record format improves retention or supports conclusions about learning effectiveness. Any later participant study would need its own design and review.
