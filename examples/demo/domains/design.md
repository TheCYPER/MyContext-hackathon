# Interface design

Fictional demo: this area explores readable interfaces for a small collection of linked notes.

## Design questions

Can the reader distinguish a confirmed connection from a possible one? Can a project show its next action without opening every related note?

## Current boundary

Visual appeal is not evidence that retrieval improved. The fictional projects need separate usability checks.
